One-time setup to connect your shared real-time database. Takes about 3 minutes.

Firebase Realtime Database is free from Google — no server needed. Both of you will see each other's changes live on any device.
1
Go to console.firebase.google.com → New project → Add a Web app
2
In the left menu → Build → Realtime Database → Create database → choose Start in test mode
3
Go to Project Settings ⚙️ → Your apps → copy the firebaseConfig object and paste below

Config is stored only in your browser. Share this HTML file with your husband — he pastes the same config once, then you're both connected.
